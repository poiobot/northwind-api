## Testing your `spore` project

First of all, open the `dot.env` and follow instructions to set environment variables for your project. Rename the file to 
`.env` and place it on the project root directory.

`spore` has generated the following directories:

- [ ] `api` -  RESTful interface implemented with `fastapi` to interact with the backend of the project
- [ ] `data` - Data Access Objects (DAOs) implementing CRUD operations for each domain entity
- [ ] `domain` - `pydantic` classes representing the entities of your project (each entity corresponds to a 
table/collection with your database)
- [ ] `lib` - `spore`'s core support libraries (copied from template everytime you generate a new project)
- [ ] `schema` - Database metadata in XML format

Feel free to analyse the code. It is intended to be easy to read and *extend*. Do not add code to the generated 
elements. If you need to add specific code, create new python classes *extending* or *using* the generated ones.

### Testing DAOs
Move to the `data` directory and run any of the `dao` scripts generated by `spore`. It will simply fetch all records 
within the specific table and print them on the console. For example, if you generated the northwind project you could
get the list of customers running:

`python customer_dao.py`

### Testing the RESTful interface of your project
To test the RESTful interface you must open a terminal outside of PyCharm (or any IDE tool that you might be using), 
load `spore`'s virtual environment. I have `spore` installed on my `src` directory in MacOS.

```
cd ~/src/spore              # or pyranha (I'll correct this later, that was the original name of the code generator)
source venv/bin/activate    # (venv) must appear as a prefix of your prompt
```
Once the virtual environment is loaded go to the `api` folder of your project:

```commandline
cd northwind/api           # replace northiwnd with the name of your project
```

Run the web server indicating the name of the webapp:

```commandline
uvicorn northwind_app:app --reload --app-dir=<HOME_DIR>/src/spore 
```

That should deploy the web server and you could interact with your project data using the browser for GET operations, or
something like `postman` for `POST`, `PUT`, or `DELETE` operations.

Try: `http://localhost:8000/northwind/customers` on your browser.

You can also paginate using the `offset` and `limit` options of `fastapi` pagination module:

`http://localhost:8000/northwind/customers?offset=10&limit=3`

Or query with conditions:

`http://localhost:8000/northwind/customers?address.country=Canada`




### Response representations

Every JSON response (lists, single records, create/update/delete results, errors and `/api/describe`)
can be requested as JSON, XML, YAML or PDF:

- `GET /northwind/customers?format=xml`: the `format` query parameter (`json`, `xml`, `yaml`, `pdf`) wins.
- `Accept: application/yaml`: otherwise the Accept header decides (`application/xml`, `text/xml`,
  `application/yaml`, `application/x-yaml`, `text/yaml`, `application/pdf`).
- JSON is the default, including for browsers, whose Accept header lists `text/html`.

An unknown `format` gets a 422. `/docs`, `/redoc`, `/openapi.json` and `/mcp` are always served as they are.
`install_representations(app)` from `lib/representation.py` wires this into the app.
